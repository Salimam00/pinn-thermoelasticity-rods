# Legacy v1/v2 materials

This directory contains earlier development notebooks, figures, tables, and numerical outputs retained for provenance only.

These files are **not authoritative for the current manuscript** and may contain values from superseded runs. References in earlier documentation to `run_benchmark.py`, `verify_results.py`, `run_repeatability.py`, `verify_fem.py`, and `run_fixed_fixed_case.py` do not describe the current repository layout.

For reproduction and review, return to the repository root and use:

- `run_all_v3.py`;
- `summary_v3.json`;
- `reproducibility_package_v3.zip`;
- DOI `10.5281/zenodo.24321123`.

The v3 archive is the sole authoritative computational release.
