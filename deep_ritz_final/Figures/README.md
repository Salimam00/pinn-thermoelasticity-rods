# Manuscript Figures

This directory contains visual results generated for the research on the Deep Ritz method applied to thermoelastic rods.

| File Name | Description |
| :--- | :--- |
| `Figure_1_Comparison of analytical and Deep Ritz displacement distribution` | Comparison of analytical and Deep Ritz displacement distribution |
| `Figure_2_Spatial distribution of the absolute displacement error` | Spatial distribution of the absolute displacement error |
| `Figure_3_Comparison of analytical and Deep Ritz axial stress distribution` | Comparison of analytical and Deep Ritz axial stress distribution |
| `Figure_4_Convergence of the dimensionless variational energy` | Convergence of the dimensionless variational energy |
| `Figure_5_temperature_distribution` | Temperature distribution along the rod |
